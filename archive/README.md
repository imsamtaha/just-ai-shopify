# Historical material

This directory preserves earlier product packages, tutorials and build tools.

Build scripts came from previous workspaces and can depend on their original external tools, directory structure or input files. Personal home paths have been replaced with `<LOCAL_HOME>` in imported text. Treat scripts as historical source until their paths and dependencies are adapted; do not execute stored GraphQL mutations without reviewing their effect.

Original binary ZIPs and media are preserved. The import manifest records the checksum of each committed imported file. Dated reports are not current readiness assertions.
