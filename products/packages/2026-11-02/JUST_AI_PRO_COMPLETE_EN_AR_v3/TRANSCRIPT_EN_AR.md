# Sales Kit PRO — tutorial transcript

English synthetic narration. Arabic written translation below each step. Original instructional slide video; fictional examples. Version 2.0, 29 October 2026.

## 1. Start with the folder map

Extract the complete v2 ZIP. Open Original, then 00_READ_ME_FIRST.md. The original package contains the complete BASIC kit, Notion import files, eight workflow playbooks, three optional JavaScript utilities, and five operating procedure documents. Start with one workflow, not every file at once.

فك ضغط v2 وافتح Original ثم ملف البداية. تتضمن الحزمة BASIC وملفات Notion وثمانية أدلة سير عمل وثلاث أدوات برمجية اختيارية وخمسة مستندات إجراءات. ابدأ بعملية واحدة.

## 2. Set up the workspace

Open 02_Notion_Import. The Markdown home page and CSV databases can be imported into your own Notion workspace using its import controls. Import each CSV as a separate database and check the headers. You can also edit the CSV files in a spreadsheet without using Notion.

افتح مجلد Notion. استورد صفحات Markdown وملفات CSV عبر أدوات الاستيراد في حسابك، أو استخدم جداول البيانات مباشرة. راجع عناوين الأعمدة بعد الاستيراد.

## 3. Configure one workflow

Choose New WhatsApp inquiry in the Workflows database. Set the owner to the person answering messages. Set a review date and adapt the tools to your process. Open the matching playbook in 03_Workflow_Playbooks. Keep its sequence: verify product, check stock, draft reply, approve, then log the result.

اختر عملية استفسار واتساب وحدد المسؤول وتاريخ المراجعة والأدوات. افتح الدليل المطابق واتبع التسلسل: تحقق من المنتج والمخزون، جهز الرد، راجعه ثم سجّل النتيجة.

## 4. Run a fictional dry run

Use a fictional customer asking for a blue linen shirt. Check a demo stock list, adapt a BASIC reply, and record the inquiry in a test tracker. Stop if price or stock is missing. Compare the result with the playbook before using the process with real customers.

جرّب استفساراً خيالياً عن قميص كتان أزرق. راجع مخزوناً تجريبياً وعدّل رد BASIC وسجّل النتيجة في جدول تجريبي. توقف إن كان السعر أو المخزون مجهولاً.

## 5. Use optional utilities carefully

The three JavaScript utilities are examples for a Node.js compatible environment. Read 04_Automation_Starter_Code/00_CODE_SETUP.md first. The files normalize a lead, flag duplicate order references, and create an approved WhatsApp draft link. They do not install a live integration or send messages. Non-technical users can skip this folder.

الأدوات البرمجية أمثلة اختيارية. اقرأ ملف الإعداد أولاً. تنظّم بيانات العميل وتكشف أرقام الطلبات المكررة وتنشئ رابط مسودة واتساب بعد الموافقة. لا تثبّت تكاملاً ولا ترسل رسائل تلقائياً.

## 6. Review before going live

Use the AI Review Checklist from 05_AI_SOP_Library. Confirm consent, factual claims, correct ownership and a recovery step. Keep a human approval step and start with one test case. Back up your workspace and review the workflow weekly. Accounts, paid tools and custom implementation are separate.

استخدم قائمة مراجعة الذكاء الاصطناعي. تحقق من الموافقة والحقائق والمسؤول وخطوة الاسترجاع. احتفظ بمراجعة بشرية ونسخة احتياطية. الحسابات المدفوعة والتنفيذ المخصص منفصلان.
